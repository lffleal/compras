# Compras

Lista de compras partilhada (Luís e Sílvia), inspirada na Buy Me a Pie!.

- App: https://lffleal.github.io/compras/
- Dados e login: Firebase (projeto `compras-38027`)
- Instalar no Android: gerar o APK em https://www.pwabuilder.com com o link da app.

Ficheiros: `index.html` (ecrãs e estilos), `app.js` (lógica e Firebase), `sw.js` (funcionar sem rede), `manifest.webmanifest` e ícones.
